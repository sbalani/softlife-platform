# Mobile UI References

These images are Playwright captures of the production web UI, sanitized in the
browser before they were saved. Names, coupon codes, notes, identifiers, and
chart values are examples rather than production data.

They are behavioral references for the native app, not pixel-perfect desktop
layouts to reproduce on a phone:

- `coupon-code-distribution.png`: keep Huaxin redemption status separate from
  the local distributed checkbox and optional handoff note.
- `analytics-incident-filter.png`: incident selection follows the same date and
  machine scope as sales analytics.
- `analytics-incident-trend.png`: incidents use a distinct dashed secondary
  series and count badge rather than changing sales totals.
- `action-report-voice-notes.png`: provide one general voice-notes control for
  the report, followed by explicit review and confirmation.

Capture date: 2026-09-07.
